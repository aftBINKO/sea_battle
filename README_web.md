# Сборка веб-версии (pygbag)

Ветка `mobile-pygbag` — порт игры в браузер через [pygbag](https://pygame-web.github.io/)
(pygame → WebAssembly). Отсюда же потом заворачивается мобильное приложение.

## Быстрый старт

Окружение сборки держим **вне** папки проекта, иначе pygbag утащит его в пакет:

```bash
python -m venv ../sea_battle_venv
../sea_battle_venv/Scripts/pip install pygbag pygame-ce
```

Запуск с локальным сервером:

```bash
PYTHONUTF8=1 ../sea_battle_venv/Scripts/python -m pygbag --port 8000 .
```

Открыть http://localhost:8000 — игра соберётся и запустится.

## Грабли, на которые легко наступить

**Запускать только сервером pygbag, не `http.server`.** pygbag докачивает колесо
`pygame_ce-*.whl` со своего `/cdn`-маршрута. На обычном статическом сервере этого
маршрута нет, pygame остаётся заглушкой без подмодулей, и игра падает на
`pygame.sprite` ещё до первого кадра. Ошибка при этом выглядит как молчаливое
зависание на «Loading, please wait...».

**`PYTHONUTF8=1` обязателен на русской локали Windows.** pygbag читает `main.py`
в системной кодировке (cp1251) и падает с `UnicodeDecodeError` на кириллице в
комментариях.

**Импорты pygame должны быть видны в `main.py`.** pygbag определяет, какие пакеты
доставить в браузер, разбирая импорты именно этого файла. Импорта из `run.py`
или подмодулей недостаточно — поэтому в `main.py` стоят явные
`import pygame.sprite`, `pygame.image` и т.д. Не удалять.

## Что отличается от десктопной версии

| | Десктоп | Браузер |
|---|---|---|
| Заставка | видео через OpenCV | статичная картинка со звуком (`menu.py`) |
| Сохранения | «Документы»/Sea Battle | память + зеркало в `localStorage` |
| `pygame.time.set_timer` | работает | не реализован в WASM — заменён счётчиками кадров |
| Размер экрана / режим окна | из настроек | всегда окно, холст масштабирует страница |

Видео (16 МБ) и исходный `screensaver.wav` исключены из веб-сборки через
`pygbag.ini` — вместо wav используется `screensaver.ogg` (49 КБ).

## Управление под палец

- **Главное меню** — сетка плиток с прямым нажатием вместо карусели с
  «текущей» кнопкой. Подписи нарезаются из `buttons.png` (лента 8×250 px с
  шагом 300), недоступные режимы не показываются вовсе.
- **Настройки** — значение листается нажатием по нему самому, стрелки лишь
  дополняют. Строки описаны таблицей `rows`, а не десятком одинаковых веток.
- **Размер клетки поля** задаётся `CELL_RATIO` в `main_functions.py`, от неё
  же зависят корабли и панель с ними. Верхний предел ≈ 0.044: дальше второе
  поле не помещается по ширине в бою.

Мышиных жестов на телефоне нет, поэтому переделаны ещё три места:

- **Прокрутка** списков и текста заданий — протяжкой пальца с инерцией
  (`DragScroll` в `main_functions.py`), колесо и стрелки продолжают работать.
- **Поворот корабля** — касанием по кораблю без протаскивания; пробел остался.
- **Опасная зона в настройках** — двойным касанием вместо правой кнопки мыши.
  Правая кнопка тоже работает, как раньше.

Из `danger_zone.png` убрана запечённая строка «нажмите ПКМ» — подсказка теперь
рисуется кодом в `Settings.menu()` и меняется в зависимости от того, взведена
кнопка или нет. Сама картинка осталась только рамкой с заголовком.

## Сброс прогресса в браузере

Кнопки опасной зоны переписывают файлы сохранений и завершают игру. В браузере
этого мало: файлы живут в памяти, а в `localStorage` остаётся прежняя копия, и
при следующем запуске `restore()` вернул бы всё назад — сброс не сработал бы
вовсе. Поэтому `Settings.restart()` сначала вызывает `persist()`, и только
потом перезагружает страницу через `platform_compat.reload_page()`.

Порядок важен: `persist()` строго после `extract_files()` и строго до
перезагрузки.

## Отладка

Ошибки Python в браузере уходят во внутренний терминал pygbag и не видны в
devtools. Поэтому `main.py` ловит исключения и печатает трассировку в консоль
браузера через `platform_compat.web_log()` — искать по префиксу `[sea_battle]`.

## Переменные окружения

- `SEA_BATTLE_DATA_DIR` — переопределяет каталог сохранений. Нужен, чтобы
  прогоны сборки не задевали сохранения установленной игры.

Дымовой прогон без окна:

```bash
SEA_BATTLE_DATA_DIR=/tmp/sb SDL_VIDEODRIVER=dummy SDL_AUDIODRIVER=dummy python main.py
```
